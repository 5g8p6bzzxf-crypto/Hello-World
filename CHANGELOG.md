# Changelog

Notable project changes are documented here.

## [1.0.0] - 2026-10-20

### Added
- Command-line greeting with default and custom names.
- Plain-text and JSON output formats.
- Unit tests using Python's built-in `unittest`.
- GitHub Actions workflow for Python 3.10–3.13.
- Functional and technical specification.
- Roadmap, contribution guide, MIT license, and issue templates.
- Python project metadata and generated-file exclusions.

### Changed
- Expanded the original one-line script into a documented, testable application.

### Notes
This is the initial documented project release. The roadmap distinguishes planned work from implemented features.

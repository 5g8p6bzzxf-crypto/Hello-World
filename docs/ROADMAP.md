# Roadmap

This roadmap separates the current starter from ideas that may be implemented later.

## Version 1.0 — Starter foundation

- [x] Preserve the original Hello World use case.
- [x] Add command-line options for name and output format.
- [x] Add unit tests using the standard library.
- [x] Document requirements and architecture.
- [x] Add contribution guidelines and issue templates.
- [x] Add license and Python project metadata.

## Version 1.1 — Quality of life

- [ ] Add continuous integration to run tests on pushes and pull requests.
- [ ] Add a supported Python-version test matrix.
- [ ] Add examples for shell scripting and piping output.
- [ ] Add a changelog.

## Version 1.2 — Learning examples

- [ ] Add a separate examples directory for beginner-friendly Python snippets.
- [ ] Add a logging example.
- [ ] Add type-checking and linting configuration if the project needs it.

## Version 2.0 — Optional extensions

- [ ] Consider a small web API only if there is a clear use case.
- [ ] Add packaging and installation instructions if distribution becomes useful.
- [ ] Add more output formats only when requirements justify them.

## Prioritization

Prioritize correctness, beginner-friendly documentation, and automated verification before adding complexity. Planned items are not implemented until their checklist is checked and the code is committed.
